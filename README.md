# 📝 Formulário de Cadastro JavaScript

Este é um projeto que desenvolvi para praticar meus conhecimentos em desenvolvimento web durante meus estudos de Análise e Desenvolvimento de Sistemas (ADS).

A ideia é criar um formulário de cadastro simples, com validação dos campos e uma tabela para visualizar os registros realizados.

## 🚀 Funcionalidades

- Cadastro de informações por meio de um formulário.
- Validação dos campos obrigatórios.
- Exibição dos cadastros em uma tabela.
- Organização e estilização da página.
- Exclusão de registros cadastrados.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura da página.
- CSS3 — estilização e organização visual.
- JavaScript — validação e funcionalidades do formulário.

## 📚 Objetivo do projeto

Praticar lógica de programação, manipulação do DOM, validação de formulários e integração entre HTML, CSS e JavaScript.
